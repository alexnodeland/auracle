# Narration pipeline for Auracle's films: tts.py (Kokoro-82M) and asr_check.py
# (faster-whisper). Python 3.10-3.12; kokoro 0.9.4 does not install on 3.13.
# Nothing in the site or the app needs any of this.
#
#   python3 -m venv .venv-voice
#   .venv-voice/bin/pip install -r www/video/voice/requirements.txt
#
# Linux takes torch from PyTorch's CPU-only index. PyPI's Linux torch wheel
# pulls ~3 GB of CUDA libraries that CPU inference never loads; the macOS and
# Windows wheels on PyPI are CPU-only already. Installed, this whole set is
# ~2.3 GB, of which torch is ~0.9 GB. Models are not pip packages: tts.py and
# asr_check.py download them from Hugging Face on first use into
# $AURACLE_VOICE_MODELS (Kokoro-82M + voices ~0.35 GB, whisper small.en ~0.5 GB).
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.14.0+cpu ; sys_platform == "linux"
torch==2.14.0 ; sys_platform != "linux"
