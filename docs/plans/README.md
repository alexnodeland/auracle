# Plans

Implementation plans for accepted proposals, named `NNN-short-title.md` after
the proposal they implement, created with `/new-plan <title> --from-proposal
NNN`. The index is in [`../README.md`](../README.md#plans).

Each task becomes a GitHub issue, labelled with the plan (`plan-008`) and in
the plan's milestone ([`../process.md` § Issues](../process.md#issues)). The
plan's progress table has an issue column that links the task's issue and,
once merged, its PR. The plan stays the design; the issue tracks the work, and
the plan's as-built section records what was built when its PR merges.
