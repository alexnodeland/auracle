# Interaction design review, September 2026

Six reviews of the instrument's interaction design, made from the evidence the
view films produced (rehearsal stills, timing sidecars in
`www/video/out/*/dry/`, the finished films) and the code, then combined into one
spec. Dated and not kept current: the spec's contracts and rules move into the
living docs and ADRs as each wave lands.

| File | What it is |
| --- | --- |
| [`spec.html`](spec.html) | The combined spec: four causes, eight rules, the time budget, six contracts (words, colour, states, undo, messages, keys), per-view decisions, engine work, four waves, and a filterable index of every finding. Open it in a browser. |
| [`findings.json`](findings.json) | The 119 findings: id, area, severity, wave, title |
| [`perform.md`](perform.md) | PERFORM (PF-01…21) |
| [`patch.md`](patch.md) | PATCH, the rack (PA-01…22) |
| [`evolve.md`](evolve.md) | EVOLVE (EV-01…20) |
| [`taste.md`](taste.md) | TASTE (TA1…20) |
| [`shell.md`](shell.md) | The shell and cross-app consistency (SH1…12, CO1…11) |
| [`performance.md`](performance.md) | Responsiveness and performance (RT1…13), with the measured timing table |
| [`BRIEF.md`](BRIEF.md) | The brief every reviewer worked from |

Each finding carries its evidence (a still, a timing with its source, a
`file:line`), what the player experiences, the principle it breaks, a concrete
recommendation, effort and confidence. Line numbers are as of commit `0117519`.

Frame paths such as `(review scratch, not kept) shframes/…` point at crops made
during the review that were not kept; the stills they came from are in
`www/video/out/<film>/dry/`, which is regenerated by a rehearsal.
